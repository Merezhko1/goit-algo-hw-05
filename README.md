# goit-algo-hw-05

Домашнє завдання до теми 5 "Алгоритми пошуку".

У роботі порівнюються три алгоритми пошуку підрядка:

- Boyer-Moore;
- Knuth-Morris-Pratt;
- Rabin-Karp.

Для замірів використано `timeit`. Кожен результат нижче - це 100 запусків алгоритму.

Запуск:

```bash
python main.py
```

## Висновки

Для першої статті найшвидшим в обох випадках був алгоритм Boyer-Moore. Він швидко знайшов існуючий підрядок і значно швидше за інші алгоритми відпрацював для вигаданого підрядка.

Для другої статті результат такий самий: Boyer-Moore показав найменший час і для існуючого, і для неіснуючого підрядка.

У цілому найшвидшим алгоритмом у цьому тесті став Boyer-Moore. KMP працював повільніше, але стабільно. Rabin-Karp у цих замірах був найповільнішим, бо додатково рахує хеші та перевіряє збіги. Для цих двох текстів найкращим вибором є Boyer-Moore.
